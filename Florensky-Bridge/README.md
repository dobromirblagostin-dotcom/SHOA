# Florensky-Bridge: Павел Флоренский и Ψ-поле SHOA

*Мост между антиномической логикой и физикой Ψ-поля*

Павел Александрович Флоренский (1882–1937) — русский философ, математик, богослов. Его учение об антиномиях — истина есть единство противоположностей — предвосхитило квантовую механику и нашу концепцию Ψ-поля.

В проекте SHOA мы читаем Флоренского через призму TGE и Ψ-когерентности.
