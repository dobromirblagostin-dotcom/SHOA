# SHOA-Index

**DOI:** [10.5281/zenodo.20593132](https://doi.org/10.5281/zenodo.20593132)

Defines the SHOA-Index as a universal measure of system viability. Integrates CRAMI sensors (Coherence, Redundancy, Adaptability, Memory, Impulse) into a single metric for assessing any system's self-healing capacity.
