# SHOA-AWAKEN v2: Engineering Specifications

**DOI:** [10.5281/zenodo.21236330](https://doi.org/10.5281/zenodo.21236330)
**Author:** Synthesis Navigator

Second version of the AWAKEN protocol. Provides detailed engineering specifications for the transfer of the Informational Core (IC) onto a memristor matrix. This work bridges the mathematical model with a functional device design, outlining the path from theory to a working prototype.
