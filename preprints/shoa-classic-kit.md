## Abstract

Version 2. This version repairs the corrupted LaTeX source of v1 (duplicate preamble, broken formatting artifacts, corrupted formulas in Criterion II and the sensor specification) and adds three substantive improvements: 
1. Pulse energy and repetition rate are now specified for the Grape pulse laser, with fluence defined as the primary dose quantity.
2. The reference to SHOA-Classic now uses the conceptual DOI, which always resolves to the latest version.
3. The calibration script `generate_table.py` is included as Appendix A, reproducing the model efficiency table directly from the published equations. 

A new section explicitly relates the three validation criteria to the quantitative predictions of SHOA-Classic v1.2. All validation criteria and the core architecture remain unchanged from v1.
